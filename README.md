# Hostel Food Selection Portal 🍽️

A web-based application designed to streamline the meal selection process for hostel residents. This portal helps hostel management reduce food waste by tracking exact meal counts, while providing students with an easy way to view menus and select their meals in advance.

## 🌟 Features

* **User Authentication:** Secure login for both students and hostel administrators.
* **Interactive Menu Dashboard:** View daily and weekly food menus clearly.
* **Meal Selection & Cancellation:** Students can opt-in or opt-out of specific meals (Breakfast, Lunch, Dinner) within a given timeframe.
* **Dietary Preferences:** Options for vegetarian, non-vegetarian, and allergen-free meals.
* **Admin Dashboard:** 
  * Add, edit, or remove menu items.
  * View daily headcounts and meal statistics to optimize cooking quantities.
  * Manage user accounts.
* **Responsive Design:** Works seamlessly on mobile devices and desktop computers.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

* [Node.js](https://nodejs.org/) (v14 or higher)
* [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
* Database installed locally or a cloud database URI

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/poornaa10/hostel-food-selection-portal.git](https://github.com/poornaa10/hostel-food-selection-portal.git)
Navigate into the project directory:

Bash
cd hostel-food-selection-portal
Install dependencies:

Bash
npm install
Set up environment variables:

Create a .env file in the root directory.

Add your database URI, secret keys, and port numbers (see .env.example if available).

Start the development server:

Bash
npm start
